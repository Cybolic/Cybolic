I've largely migrated away from GitHub following their string of security incidents, and their push towards claiming training rights over any repo, regardless of the choices set by the author.

I work in web development (Full-stack and DevOps), and thoroughly enjoy using Nix for practically everything.

If you've been using Linux for a while, you may have used one of my projects:
- [Vineyard](https://vineyardproject.org) - One of the first desktop tools for Wine management
- [LinReaper](https://forum.cockos.com/showthread.php?t=26690) - The installer for running Reaper on Linux, before the native port
- [CeeMedia](https://sourceforge.net/projects/ceemedia/) - One of the first movie collection management tools
- [GryPhon](https://gryphon.sourceforge.net) - The one and only themeable CD player
